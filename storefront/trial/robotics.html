Robotics Engineering · Module 1

Your First Circuit: Blink an LED

Every robot — no matter how complex — is built from this. A microcontroller deciding when to send voltage somewhere. Get this one right and understand why it works, and the rest of the course is just more of the same idea.

🎉 Lesson complete. You've built and understood your first circuit — Module 2 is microcontrollers & C++.

What you need

~2 min · total cost about $15 if you don't have a kit

  • An Arduino Uno (or any Uno-compatible clone) and its USB cable
  • A solderless breadboard
  • One LED (any colour)
  • One 220 Ω resistor (colour bands: red-red-brown-gold)
  • Two jumper wires
  • The Arduino IDE installed on your computer (free)

Step 1 · The only electronics you need today

Volts, current, resistance

Three quantities explain almost everything in a beginner circuit:

QuantityUnitPlumbing analogy
Voltage (V)voltsWater pressure pushing through the pipe
Current (I)ampsThe flow rate of water
Resistance (R)ohms (Ω)How narrow the pipe is

They're tied together by Ohm's Law:

V = I × R        →        I = V / R

An Arduino output pin gives 5 V. An LED wants only about 10–20 mA (0.01–0.02 A) or it burns out. An LED itself drops roughly 2 V. So the resistor has to "use up" the other 3 V:

R = (5V − 2V) / 0.015A  =  3 / 0.015  ≈  200 Ω

That's why the lesson calls for a 220 Ω resistor — it's the nearest common value that keeps the current safe. Skip the resistor and the LED (or the pin) dies.

Quick check: why does the circuit need the resistor?

To store energy for the LED To limit the current so the LED isn't destroyed To make the current flow the right direction

Step 2 · Build the circuit

Follow the current from pin 13 back to GND

Video: breadboard wiring, close-up (full course)
  1. Push the LED into the breadboard so its two legs are in different rows. The long leg (anode, +) goes toward the Arduino pin side.
  2. Connect one end of the 220 Ω resistor to the row with the LED's short leg (cathode, −). Put the other end in an empty row.
  3. Jumper wire from Arduino pin 13 → the LED's long-leg row.
  4. Jumper wire from the resistor's free end → Arduino GND.

Trace it out loud: pin 13 → LED (anode to cathode) → resistor → GND. Current can only flow when pin 13 is HIGH (5 V) and it has a complete path back to ground. Right now the pin is doing nothing — that's the code's job.

Orientation matters

An LED only conducts one way. If it stays dark later, the first thing to try is flipping it — long leg toward pin 13.

Step 3 · The code, line by line

Arduino C++ · upload with the → button in the IDE

const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);   // pin 13 will send voltage out
}

void loop() {
  digitalWrite(LED_PIN, HIGH); // 5V on  → LED lights
  delay(500);                  // wait 500 ms
  digitalWrite(LED_PIN, LOW);  // 0V     → LED off
  delay(500);                  // wait 500 ms
}
  • const int LED_PIN = 13; — a name for the pin number so the code reads clearly and you change it in one place.
  • setup() runs once at power-on. pinMode(..., OUTPUT) tells the chip this pin will drive voltage rather than read it.
  • loop() runs forever, top to bottom, then repeats.
  • digitalWrite(pin, HIGH) puts 5 V on the pin; LOW puts 0 V.
  • delay(500) freezes everything for 500 milliseconds. Change both to 100 for a fast blink, 1000 for a slow one.

Why this pattern matters

setup() then loop() is the shape of every Arduino program you'll write — including the one that drives your rover's motors in Module 6. You're not learning a toy; you're learning the structure.

Step 4 · When it doesn't work

The four things that go wrong first

SymptomMost likely cause
Nothing lightsLED is backwards — flip it (long leg → pin 13)
Still nothingA wire is in the wrong row; trace pin 13 → LED → resistor → GND again
Upload fails in the IDEWrong board or port selected under Tools
LED very dim or flickersResistor too large, or a loose jumper in the breadboard

Debugging hardware is a skill in itself: change one thing at a time and re-test. That discipline is what separates people who finish robotics projects from people who don't.

Your challenge

Do this before moving on

  1. Get the basic blink working.
  2. Add a second LED on pin 12 (its own resistor) and make the two alternate — one on while the other is off.
  3. Make an SOS pattern: three short blinks, three long, three short, then a pause.
