Lesson 1 · Output — the blink, properly understood

Recap + the one upgrade that matters

If you haven't done the public blink lesson yet, do it first — it covers the wiring and Ohm's law: Your First Circuit →

Here's the upgrade: delay() is a trap. While the Arduino is inside a delay(500) it can do nothing else — it can't read a sensor, it can't check a button. Real robots never block. Same blink, non-blocking:

const int LED_PIN = 13;
unsigned long lastToggle = 0;
const long interval = 500;
bool ledOn = false;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  unsigned long now = millis();          // ms since power-on
  if (now - lastToggle >= interval) {
    lastToggle = now;
    ledOn = !ledOn;                       // flip the state
    digitalWrite(LED_PIN, ledOn ? HIGH : LOW);
  }
  // ...loop keeps running freely; add more checks here later
}
  • millis() is a clock that never pauses your program.
  • You store when you last acted and check whether enough time has passed.
  • This "check the clock" pattern is how a robot juggles motors, sensors and timing at once.

Lesson 2 · Input — reading a button

digitalRead + the pull-up resistor

Video: wiring a button without a floating pin

Wire a push-button between pin 2 and GND. The catch: when the button is not pressed, pin 2 is connected to nothing — it "floats" and reads random noise. The fix is a pull-up resistor that gently ties the pin to 5 V, and the Arduino has one built in:

const int BUTTON = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON, INPUT_PULLUP);   // idle = HIGH, pressed = LOW
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  bool pressed = (digitalRead(BUTTON) == LOW);   // inverted!
  digitalWrite(LED_PIN, pressed ? HIGH : LOW);
}
Button statePin 2 readsWhy
ReleasedHIGHInternal pull-up holds it at 5 V
PressedLOWButton connects the pin straight to GND

The gotcha

With INPUT_PULLUP the logic is inverted — pressed is LOW. Every beginner forgets this once. Now you won't.

Lesson 3 · Analog input — a dimmer knob

analogRead, the Serial Monitor, and map()

Digital pins see only HIGH or LOW. Analog pins (A0–A5) measure a voltage between 0 and 5 V and give you a number from 0 to 1023. Wire a potentiometer: outer legs to 5 V and GND, middle leg to A0.

void setup() {
  Serial.begin(9600);          // open a text link to your computer
}

void loop() {
  int raw = analogRead(A0);            // 0..1023
  int percent = map(raw, 0, 1023, 0, 100);
  Serial.print("knob: ");
  Serial.print(percent);
  Serial.println("%");
  delay(200);
}
  • Open Tools → Serial Monitor (set to 9600 baud) to watch the numbers change as you turn the knob.
  • map() rescales one range to another — here 0–1023 becomes 0–100.
  • Serial is your #1 debugging tool for the rest of the course: print a value, see what the robot actually thinks.

Put it together

Combine all three lessons: use the knob's value as the blink interval in the non-blocking code from Lesson 1, and the button to pause it. That's a real little program — input, timing and output working at once.

You can now do output, digital input and analog input.
