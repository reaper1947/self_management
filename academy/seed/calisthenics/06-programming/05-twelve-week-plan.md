A concrete 12-week block. Pick **one static** and **one dynamic** goal, run the 3-day
split, deload weeks 6 and 12.

## Example goals

| Level | Static goal | Dynamic goal |
|---|---|---|
| Beginner | 30 s freestanding-ish handstand / 20 s tuck FL | First 3 strict pull-ups + 5 dips |
| Intermediate | 15 s advanced-tuck front lever | First strict muscle-up |
| Advanced | 8 s straddle planche | +30% bodyweight weighted pull-up |

## The block

**Weeks 1–2 — technique & base.** Learn the progression steps, nail form, moderate volume.
Set your working step for each skill.

**Weeks 3–5 — build.** Add one lever (reps/seconds/leverage/load) per exercise per week.
Push the static holds; grind the dynamic strength.

**Week 6 — deload.** Half volume, no max work.

**Weeks 7–9 — intensify.** Harder progression steps, lower reps, more rest. Introduce
explosive work. Start skill-test attempts if close.

**Weeks 10–11 — peak.** Lowest volume, highest intensity. Frequent short skill practice.
Test attempts each week, fresh.

**Week 12 — deload + retest.** Redo the assessment. Log everything. Pick the next block's goals.

## Track this every session

Date · exercise · step/variation · sets×reps or seconds · load · RPE (1–10) · one note.

That log is the most valuable thing you'll build in this course. Re-read it before planning
the next block.
